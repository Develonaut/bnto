# Recipe Ideas

Brainstorming space for potential recipes. No commitment, no specs — just ideas. When one matures, promote it to `bntos.md` with full classification and node requirements.

---

## Social Media Posting

- Post to Bluesky (text + images via AT Protocol — zero platform approval needed)
- Post to Instagram (carousel support, 4:5 crop — requires Meta App Review)
- Post to Threads (comes with Instagram approval)
- Post to Pinterest (2:3 pin format, native scheduling support)
- Post to Facebook Page (comes with Meta approval)
- Post to TikTok (photo/video — double-gated approval)
- Post to X/Twitter (500 posts/month app-wide free tier limit — may not be viable)
- Cross-post to all connected platforms (the big one — compose once, format per platform, send everywhere)

## Image Prep for Social

- Format images for Instagram (resize to 1080px, 4:5 crop)
- Format images for Pinterest (resize to 1000x1500, 2:3 ratio)
- Format images for Bluesky (resize to 1000px longest side, 1MB max)
- Auto-generate platform-optimized variants from a single source image
- Add watermark before sharing (protect art, bnto already has image nodes)

## Content Management

- Schedule post for later (compose now, post at specified time)
- Bulk import from Instagram data export (JSON parse → extract posts + images)
- Bulk import from Bluesky history (API pull → extract posts)
